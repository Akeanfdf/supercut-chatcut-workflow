# 特效感知剪辑与 ChatCut 可视化工作流

本规范支持两种入口：参考片＋需求＋素材，以及文案/主题＋素材。两种入口最终进入同一套素材覆盖、质量门、特效规划、ChatCut 审阅和终版验收流程。

## 1. 职责边界

Codex 负责理解需求、分析素材、设计镜头、识别真实节拍、选择特效、规划文字和生成提示词；本地运行时负责确定性分析与渲染；ChatCut 负责素材管理、多轨时间线、播放、基础剪辑调整和用户确认。

ChatCut 不应自行替换既定规划或调用内置 AI。最终可编辑时间线必须保留原始素材关系；精确特效代理只放在预览轨，不替代源镜头。

## 2. 入口与触发

### 参考片驱动

输入：用户需求、参考视频、目标素材，以及可选文案、BGM、人物参考、时长、画幅、帧率和视频模型。逐镜头提取可复用视觉语法，不复制参考片的人物、品牌、台词或具体故事。

### 原创规划驱动

输入：文案、脚本或主题、目标素材，以及可选人物、产品、场景、平台、画幅和模型。把文案拆成叙事段落和信息节拍，设计原创视觉语法，并为缺失镜头生成补拍清单或模型提示词。

标准触发词为：`执行超级剪辑终版工作流`、`按终版工作流剪辑`、`参考片复刻终版`、`原创规划终版` 或 `$supercut-chatcut-workflow`。

快速链接模式可直接提供两个公开 B 站视频链接和一段本地音乐。获取前必须由用户确认素材权利；系统只解析 BV 号、分P和公开短链重定向，不读取浏览器 Cookie，不绕过登录、付费或访问控制。远程获取失败时生成 `needs_input` 报告并要求本地合法素材。

## 3. 状态机

```text
triggered
→ brief_ready
→ reference_or_design_grammar_ready
→ asset_coverage_ready
→ needs_input | quality_gate_1_passed
→ edit_plan_ready
→ chatcut_synced
→ user_review
→ conflict_reported | quality_gate_2_passed
→ final_edit_ready
→ approved
→ rendered_or_delivered
→ verified
```

关键输入不完整、素材有硬缺口、参考时间线有缺口/重叠或综合评分低于 85 时进入 `needs_input`，不得伪装完成。发生双向修改冲突时进入 `conflict_reported`，不得静默覆盖。

## 4. 阶段一：需求标准化

生成 `edit_brief.json`，记录：目标与受众、平台、画幅、时长、帧率、核心信息、叙事顺序、主体/服装/产品/道具/场景约束、允许和禁止素材、特效强度、文字策略、目标模型、生成权限、必须保留的台词/动作/声音、交付方式和 ChatCut 审阅政策。

先从当前任务、已附文件和当前 ChatCut 工程补全信息。只有缺失值会实质改变结果或权限边界时才集中提问。

## 5. 阶段二：视觉语法

### 参考片解析

输出无缺口、无重叠的逐镜头时间轴。每镜头包含：起止时间码、时长、首尾画面、主体外观锚点、动作轨迹、表情、空间前中后景、景别、焦段、构图、景深、运镜方向/速度/稳定方式、光线、色温、材质、声音、转场、镜头功能、连续性锚点和不得复制内容。

随后生成 `visual_grammar.json`，只保留可复用方法，来源标记为 `reference_extracted`。

### 原创视觉语法

根据文案和素材生成叙事阶段、情绪曲线、镜头功能、景别递进、构图原则、主体与相机运动关系、光线/色温/材质方向、时长分布、转场与节拍规则、文字/音乐/环境声/音效策略、人物一致性和动作连续性规则，来源标记为 `designed`。

## 6. 五类语法与规划粒度

- `Narrative Grammar`：故事阶段、信息顺序与情绪曲线。
- `Rhythm Grammar`：真实强拍、次强拍、Onset、持续段、抬升、释放与留白。
- `Visual Grammar`：主体、景别、构图、运动、光色与材质。
- `Transition Grammar`：动作、构图、遮挡、亮度、形状与声音衔接。
- `Effect Grammar`：素材条件、适配评分、强度、密度、重复惩罚与禁用规则。

规划粒度固定为 `Sequence → Shot → Beat Unit → Micro Visual Event`。BPM 只提供周期骨架，实际波形中的 Beat、Onset、重拍与动作落点决定候选切点。叙事停留、动作完成、匹配切可以覆盖机械卡点。

## 7. 阶段三：素材覆盖与语义分析

生成 `asset_coverage.json`：每镜头所需素材、当前覆盖状态、可直接使用/需裁切/需加工/缺失、动作前后余量、特效输入条件、人物/道具/场景锚点和置信度。

同时识别事件、主体身份、动作起点/方向/落点、表情、空间关系、遮挡轮廓、主体位置/速度、视线方向、亮度、色温、材质、安全区域、动作声和音频节拍。

缺失素材分为：现有素材可重组、建议补拍、建议提供更多素材、允许时可由目标模型生成、无法安全推断必须询问。完整实录先机器初筛再人工视觉复核；音量峰值、HUD 变化、菜单和失败界面不能直接当高光。

## 8. 阶段四：镜头蓝图与提示词

生成 `shot_blueprint.json`。每镜头包含编号、用途、时长、首帧状态、主体与空间位置、动作过程/轨迹/速度/落点、表情、相机位置/景别/焦段/运镜、光线/色温/材质、尾帧状态、下一镜头锚点、素材来源、声音和候选特效。

需要生成的镜头写入 `generation_prompt_pack.json`，包括全局一致性、逐镜头提示、首帧、动作、运镜、尾帧、衔接、模型参数与全局/逐镜头禁止项。未指定模型时只生成模型中立版，真正提交前确认模型和生成权限。

## 9. 阶段五：质量门一

检查文案映射、目标时长、镜头起点/过程/终点、人物/服装/道具/空间一致性、动作连续性、素材缺口、提示词可执行性、参考片版权边界、特效输入条件、正式文字来源和节拍结构。

综合分低于配置阈值（默认 85）或任一硬失败时进入 `needs_input`。向用户明确列出缺什么、影响、需要的素材/信息和不补充时的降级方案。

## 10. 阶段六：剪辑、特效、文字与声音

输出 `supercut-edit-plan-v2`：素材顺序、入点、出点、时长、速度曲线、故事阶段、主要切点、镜头内部事件、字幕、BGM、原声、SFX、特效位置/参数、理由与备用方案。

特效采用 catalog-first。全部 38 项必须可被统一运行时识别，但只有素材条件成立时才自动选择。默认 `balanced`：明显效果平均最多每六秒一个，两个强效果至少间隔六秒，不连续堆叠强效果，字幕/对白/关键信息期间优先可读性；素材条件置信度低于 0.7 时退回硬切、动作匹配、构图匹配、声音桥或基础转场。

文字先确认正式来源并与实际音频对齐，再标记语义角色、关键词、重复关系和阅读时间。位置根据目标帧主体、字幕和构图决定，不能只套固定安全区。用户删除的文字或音效不得自动恢复。

## 11. 阶段七：ChatCut 同步

标准轨道：

- `SC_STORYBOARD`：缺失/待生成镜头占位；
- `SC_MAIN_A / SC_MAIN_B`：原始素材或可编辑代理；
- `SC_VFX_PREVIEW`：精确特效代理；
- `SC_TITLES`：歌词、字幕、标题、文字动效；
- `SC_AUDIO`：原声、BGM、旁白；
- `SC_SFX`：动作声与转场声；
- `SC_NOTES`：效果名称、理由、风险和待确认项。

本地先生成 1080p 审阅代理、精确特效代理、文字/音乐/音效预览和效果选择报告。生成镜头未完成时先显示故事板占位，不直接批量生成。同步后必须读取项目结构并检查可见时间线，不能只凭变更请求成功就报告完成。

## 12. 阶段八：用户审阅与 Pull

用户可调整镜头顺序、入出点、时长、速度、特效区间、音乐、文字，或删除/替换镜头。显式 Pull 后重新检查动作连续性、素材余量和特效条件。本地与 ChatCut 同时修改时生成冲突报告。

## 13. 阶段九：质量门二与终版

检查故事结构、镜头节奏、人物/服装稳定、动作/视线/轴线连续、背景与物理关系、特效必要性、转场依据、文字遮挡、SFX 对齐、黑帧、跳帧和音画断裂。

必须同时进行：时间线结构读取、实际合成像素检查、带声音的整段播放感知验收。用户明确确认后，才形成终版或导出文件。最终验收包含完整解码、分辨率、帧率、时长、同步、静音、异常闪烁、主体一致性、动作连续性、背景稳定、特效帧位和文字安全。

## 14. 案例硬规则

- 三角洲整局：一个完整实录入口即可；机器初筛后人工剔除菜单假高光。
- 枪体锁屏：枪体/手部、HUD、旧背景、新背景和效果层分开建模。
- 故障燃烧：冻结旧枪、新背景提前进入、轮廓燃烧退出、故障只遮末帧；不随意重绘原枪械。
- 镜面滑屏：模板记录运动曲线与声音策略；被删音效不自动恢复。
- 回忆快闪：一个 Shot 内允许多个 Beat Unit 驱动背景切换、缩放、色差和曝光脉冲。
- 九宫格/蒙版卡点：每格、条带、扇叶或孔洞独立绑定素材，不复用同一画面伪装多源拼贴。
- 动态歌词：正式歌词优先；重复句保留并允许变化排版。
- AMV/MAD：强拍承担主要切换，动作完成、匹配切和情绪停留可覆盖机械卡点。

## 15. 通用生成禁止项

禁止人物身份、脸型、年龄、发型、服装颜色漂移；道具消失或变形；手指/肢体错误；动作中途重置；方向和速度突变；瞬移、漂浮、穿模；碰撞与重力错误；视线混乱；背景结构跳变；光向闪烁；色温和纹理漂移；轴线无故翻转；焦段突变；闪烁和重复帧。

## 16. 完成定义

只有状态不为 `needs_input`/`conflict_reported`、时间线无意外空隙/重叠/黑帧/错层、视觉语法已落实到镜头、主要切点经过真实 Beat/Onset 与动作落点双检、特效条件成立、文字准确可读、合成像素与有声全片已验收、ChatCut 保留可编辑源关系，才可报告终版完成。
