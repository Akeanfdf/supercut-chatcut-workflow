# 《通往夏天的隧道》案例

参考片：[BV17a8CzLEgZ](https://www.bilibili.com/video/BV17a8CzLEgZ/)。目标素材为用户合法持有的本地视频，音乐为用户提供的本地音频。

系统先把参考片拆成 70 个无缺口镜头，再通过同源 BGM 的 2.720 秒偏移映射继承参考片切点。叙事结构为：40 个盛夏环境微镜头 → 13 个人物连接镜头 → 9 个隧道推进镜头 → 2 个情绪停留长镜 → 6 个安静收束镜头。

该案例形成于 v1.1，公开的 96/97 质量分不追溯声明已经执行 v1.2 的 `supercut-beat-map-v2`。v1.2 起的新任务会额外保存波形观测 Onset、推断 Beat/Downbeat、切点命中率与毫秒误差；只有这些指标通过才能宣称严格真实卡点。

最终时间线为 68 秒、60 fps、4080 帧，包含 27 个短转场；BGM 入点偏移 2.720 秒，多频段音频相关度为 0.696807。第一质量门为 96/100，第二质量门为 97/100。

公开资料只包含抽象时间线、统计、质量报告和经授权的终版前 20 秒。完整参考片、完整电影、原始 BGM、ChatCut 工程 ID 和本机路径不进入仓库。
